# 🎯 Radial Menu Launcher (СКМ-меню)

**Radial Menu Launcher** — это умное контекстное радиальное меню для Windows, которое вызывается нажатием **средней кнопки мыши (СКМ)**. 

Программа сама понимает, где вы кликнули:
*   📂 **По выделенному файлу в Проводнике** — откроет меню действий с файлом.
*   🖥️ **По пустому месту** — откроет лаунчер для запуска приложений и ссылок.

---

## ✨ Основные возможности

*   **Контекстное меню файлов**: Открытие папки, копирование пути, создание ZIP-архива, дублирование, удаление в корзину.
*   **Работа с изображениями**: Встроенный интерактивный редактор для быстрой обрезки (кропа) и изменения размера фото.
*   **Лаунчер приложений**: Запускайте программы, игры или веб-сайты (URL) в один клик.
*   **Полная кастомизация**:
    *   Добавление и удаление приложений/ссылок.
    *   Изменение названий и установка собственных иконок для любого элемента.
    *   Настройка внешнего вида: радиус меню, прозрачность, цвет фона и акцентный цвет.
*   **Вложенные меню (Подменю)**: Наведите курсор на сектор «Управление» и задержите на долю секунды, чтобы открыть мини-меню быстрых действий.
*   **Удобное управление**: Меню закрывается по клавише `Esc`, правому клику или клику в любом пустом месте экрана.
